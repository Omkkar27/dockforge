# Container Runtime (TypeScript)

A lightweight container runtime built with TypeScript and Node.js. It provides basic image and container management with lifecycle operations.

## Features

- Pull and manage images
- Create and remove containers
- Start and stop containers
- Container status management
- Environment variable configuration
- Port mapping
- Container logs

## Tech Stack

- TypeScript
- Node.js

## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/container-runtime-ts.git
cd container-runtime-ts
```
